## ✨ Features
1. **Executive Dashboard**:
   - Welcome banner with live next-class countdown and quick-actions.
   - Animated statistics cards (Attendance: 92%, CGPA: 9.0, Subjects: 6, Assignments: 18/20).
   - Interactive Chart.js SGPA trajectory comparing student performance against cohort benchmarks.

2. **Attendance Analytics & Smart Simulator**:
   - Circular progress indicator showing aggregate attendance (92.4%).
   - Subject-wise attendance meters with safe-margin calculations.
   - Attendance projection simulator calculating bunk limits while staying above the mandatory 75% threshold.
   - Monthly attendance bar chart tracking conducted vs. attended classes.

3. **Academic Results & Performance**:
   - Continuous internal marks breakdown across Midterms, Assignments, and Quizzes.
   - Grade distribution doughnut visualization for 1st Semester core courses.
   - Course filtering and interactive assessment progress.

4. **Weekly Timetable (Monday – Saturday)**:
   - Day view timeline highlighting ongoing, completed, and upcoming classes.
   - Full-week matrix schedule view.

5. **Subjects & Curriculum**:
   - 1st Semester coursework breakdown (Python Programming, Engineering Mathematics, Digital Logic, DSA Lab, Basic Electrical & Electronics, Technical English).
   - Course module modal viewers and faculty details.

6. **Assignments & Coursework**:
   - Deadline badges, status filters, and priority urgency markers.
   - File dropzone submission modal with drag-and-drop capability.

7. **Institutional Tools**:
   - Official Printable Student Digital ID Card with QR/Barcode formatting.
   - Printable Official Academic Grade Sheet / Transcript modal.
   - Notification and Announcement feeds with priority filtering.
   - Global search bar (`⌘K` / `Ctrl+K`) for subjects, faculty, and coursework.
   - Clean Dark / Royal Light mode theme engine with `localStorage` persistence.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Using Node.js
npx serve .

# Or using Python
python -m http.server 8080
```

Visit `http://localhost:8080` in your browser.
